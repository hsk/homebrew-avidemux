# Local Avidemux

## How do I install these formulae?

`brew install local/avidemux/<formula>`

Or `brew tap local/avidemux` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "local/avidemux"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
